# TutorLink VUT
**Web Development 3.2 Project**

## Description
TutorLink VUT is a student-focused website designed to help students explore tutoring information and academic subjects. It supports English and Afrikaans, responsive navigation, dark mode, subject filtering, and contact form validation.

## Technologies
- PHP
- HTML, CSS and JavaScript

## How to Run
1. Open the project in GitHub Codespaces.
2. Open the terminal in the folder containing `index.php`.
3. Run:

   ```bash
   php -S 0.0.0.0:8000
   ```

4. Open the **Ports** tab and click the forwarded address for port `8000`.

**Website:** [TutorLink VUT](https://glorious-palm-tree-v67p6xggpp9wfp4ww-8000.app.github.dev/)

*Note: The website link works only while the Codespace and PHP server are running and the port is accessible.*
